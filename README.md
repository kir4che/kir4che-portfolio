# Molly Su Portfolio

## Tech Stack

Next.js · React · TypeScript · Tailwind CSS · Motion · Three.js

## Development

```bash
pnpm install
pnpm dev
```

開啟 [http://localhost:3000](http://localhost:3000) 查看網站。

## Build

```bash
pnpm build
```

專案使用 Next.js static export，並透過 GitHub Actions 部署至 GitHub Pages。
